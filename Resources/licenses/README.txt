Lizenzen der Software, die mit QuartzHub ausgeliefert wird
==========================================================

QuartzHub selbst steht unter der GPL-3.0-or-later (QuartzHub-LICENSE.txt).

Mitgeliefert und unverändert:

- Node.js (node-LICENSE.txt): die Laufzeit für Quartz, npm und die Helfer. Die Datei enthält auch
  die Lizenzen der Bibliotheken, die Node einbindet, und die von npm.
- git (git-LICENSE.txt): aus dugite-native (GitHub Desktop), GPLv2. Ausgedünnt: ohne Git Credential
  Manager, git-lfs, Übersetzungen und gitweb. Quelltext: https://github.com/git/git

Gebündelt in den Helfern (Contents/Resources/helpers):

- yaml (ISC), TypeScript (Apache-2.0); ihre Lizenztexte stehen am Ende der jeweiligen .cjs-Datei.
