# Gleichstand: Plugins und Wartung

Rohfassung, nur gelesen (2026-11-09). Abkürzungen in den Spalten:

- **QuartzControl**: Pfad unter `~/Development/QuartzControl/src/` (`routes/…`, `components/…`).
- **Handbuch**: Kapiteldatei unter `~/Obsidian/QuartzProjekte/QuartzControl-Handbuch/`.
- **QuartzHub**: Pfad im Repo `~/Development/QuartzHub/`.
- **P4** = `docs/decisions/phase-4-oberflaeche.md` (an der laufenden App), **P3** = `docs/decisions/phase-3-dienste.md`
  (Kern, Golden-Tests, VM; kein Beleg „an der App“).
- „Schlüssel vorhanden“ heißt: der Katalog-Schlüssel aus QuartzControls Code wird in der genannten QuartzHub-Datei
  als Literal aufgerufen. Abgleich per Skript über alle `t('…')`-Aufrufe der Routen und von
  `components/PluginOptionsForm`, `SitePreview`, `ReadmeText`: Außer Griff-Beschriftungen fürs Ziehen
  (`pluginsInstalled.dragHandle`, `dragHint`, `formsEditor.dragField`), den Panel-Labels (`*.panelLabel`) und
  `formsEditor.noSuchPage` steht jeder Schlüssel auch in QuartzHubs Code.
- Der UI-Test `testPluginsReorderAndSwitchWriteTheConfig` (`UITests/SmokeTests.swift`) prüft Umsortieren, Schalter und
  Zähler auf Installiert; P4 nennt ihn nicht, deshalb zählt er hier nur als Hinweis.
